# Synthetic example — Decision memo

This is illustrative authoring data, not an executed or verified run. Options, costs and owner
status below are synthetic inputs; they represent no real approval or resource commitment.

## Input

A supplied brief asks whether to keep a reversible prototype or replace it with a larger service.
The prototype has a supplied small maintenance assumption; the replacement has an uncertain cost
and more operational dependencies. The owner is named but has supplied no answer.

## Expected output

The memo compares alternatives, evidence, assumed costs, risks and reversibility. Its suggested next
step is a scoped validation of the reversible prototype: recommendation only, not an implementation
instruction. It states owner decision: pending and records which evidence would change the proposal.

The important-rule destination would be a shortest current rule plus necessary conditions in owning
`DECISIONS.md` only after an actual owner decision. Full original options/answers/rationale belong
verbatim in owning `RESOLVED.md`, with the same stable ID and anchored links. This example archives
nothing because the question is still open.

# Capture and clarify an idea

Authoring package only — not runnable. See the
[Shared execution contract](../README.md#runtime-boundary) for permissions, full commit markers,
failure recovery and future manual/scheduled execution. No live research or provider call occurs.

## Inputs and evidence

- Original idea/source and owner: `<original source links, IDs and responsible owner>`.
- Defaults: selected-document, explicit-baseline, product, idea-brief.
- Local destination declaration: `Plans/flows/ideas-capture.md`.
- Source selection/provenance: `<actual supplied revisions, dates, audience and scope>`.
- Required sources: original note and provenance, problem audience outcome and constraints or explicit unknown, owner and unanswered questions.

Record source references, original wording, assumptions, objections and unknowns separately. For
missing mandatory evidence, block its dependent claim; preserve independent work and rejected
alternatives. A report/proposal is not validation, an owner decision or an action approval.

## Domain steps

### capture

Preserve the original note, source references, author/context and original IDs. Separate what the note actually says from the agent's interpretation; do not rewrite the source or create a project.

### clarify

Describe the problem, audience, desired outcome, constraints and open questions. A named solution in a rough note stays a candidate, not a prescribed solution; unknown need/audience/evidence remains explicit.

### report

Return the original-note reference, clarified brief, assumptions and questions. Hold dependent solution commitments until actual evidence/answers exist; completing a brief is not approving a feature.

## Approval boundary and outcome

Committing to a solution, editing original notes, assigning work, creating a project or sending the brief requires a separate preview and explicit approval. This package only produces a proposed clarification.

The local brief/report is complete without a tracker. A declared handoff is data only, not a sent
request; no source changes, roots, projects, experiments or scheduled runs are created by this package.

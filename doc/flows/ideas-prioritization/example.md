# Synthetic example — Idea prioritization

This is illustrative authoring data, not an executed or verified run. Relative impact/effort claims
are synthetic assumptions, not measured business effects or approved priorities.

## Input

One supplied candidate claims broad impact but provides no supporting customer evidence. Another
candidate has a narrower supplied need and a reversible validation approach. The owner has not
provided weights or an actual priority choice.

## Expected output

| Criterion | Broad candidate | Narrow candidate |
| --- | --- | --- |
| Impact/confidence | Claimed high impact; confidence: unknown | Supplied narrow need; generalization unknown |
| Effort/urgency | Assumptions, urgency unverified | Small validation proposed; urgency unverified |
| Strategic fit/reversibility | Goal link needs confirmation; broad commitment costly to reverse | Stated goal link and reversible validation proposal |

No numerical score is invented. The report exposes evidence gaps and possible validation order;
it is not an approved priority or a commitment to the supposedly higher-impact idea.
